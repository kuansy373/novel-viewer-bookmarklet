# ブックマークレットとは
- Webブラウザのブックマーク機能を利用して、Minify済みのJavaScriptコードを実行する仕組み、またはそのプログラムのことです。
  - Minify（ミニファイ）とは、空白と改行を除去する処理のことです。Mangle（マングル）という、変数名や関数名の短縮もMinifyに含まれることがありますが、Mangleはブックマークレットの実行には必須ではありません。
- モバイル端末（スマホ・タブレット）でも利用できます。
- PC版Vivaldiのように、ブックマークではない機能（コマンドチェイン）から実行できる場合もあります。

# 試してみよう
```
javascript:alert('ブックマークレットを実行できました！');
```
1. 任意のページを**ブラウザのブックマークに追加**します。（どのページでもOK）
  > - Chromeでは追加したブックマークが「リーディング リスト」に分類されるとURLを編集できなくなるので、「ブックマーク バー」などへ分類しましょう。

2. 追加したブックマークの**名前を変更**します。（自由な名前でOK）
  > - ページをブックマークしたとき、そのまま名前変更できることもありますが、できない場合は「ブックマーク一覧」等から探し出して編集してください。
  > - モバイルChromeではアドレス欄に**名前を入力し呼び出してから実行する**ため、短い名前がおすすめです。ただし短すぎると他の検索候補に埋もれるため、**短すぎない一意なワード**（例：「てすとあらーと」など）にしましょう。

3. 次に**URL欄を空に**して、 `javascript:` から始まる上記ブックマークレットコードを貼り付けます。
  > - `javascript:`も含めてください。
  > - この時点で「ブックマークレットの作成」は完了です。

4. 実行したいページにいる状態で、作成したブックマークレットを実行してください。
  > - 「ブックマーク一覧」等から探してタップしたり、「ブックマーク バー」からタップしたり、アドレス欄に名前を入力して表示されたものをタップして実行できます。

# Androidでうまくいかない
- Android では、[単一行の文字数制限5000文字](https://developer.android.com/reference/android/widget/TextView#setSingleLine%28boolean%29) により、長いスクリプトだと全て貼り付けられないかもしれません。私の使っている端末では、ちょうど5000文字で途切れており、URL欄の上限でもクリップボードの上限でもないことを確認したため、これが原因だと考えています。
  - メモ: 複数端末で同期している場合、端末A（制限なし）で正常に貼り付けられたあとに端末B（制限あり）でURL欄を確認すると、端末Bの状態が同期され、端末Aまで途切れた状態になることがありました。
  - 解決策: mangleしても5000文字を下回らない場合、長いスクリプトを外部（GitHubの公開リポジトリなど）に置き、短いコードで読み込む方法で解決できます。（この場合、リポジトリに置くコードはMinify不要になります）
